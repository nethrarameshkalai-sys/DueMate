# DueMate

DueMate is a colorful, interactive, and modern student academic productivity web application designed to help students manage their academic activities in one place.

## Features

- Timetable
- Tasks & Deadlines
- Subjects
- Notes & Study Materials
- Groups
- Group Tasks & Files
- Group Games & Challenges
- Leaderboards
- Calendar
- Notifications
- Profile & Settings
- Light, Dark & System Themes
- Responsive Design

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Node.js
- Express.js
- MySQL
- Git & GitHub

## Team

DueMate is developed by a 3-member team.

The project is divided into frontend UI/UX, feature development, and backend/database responsibilities.
